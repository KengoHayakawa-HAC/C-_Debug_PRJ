# Techer：運営者用教材まとめ

このブランチはユーザーの依頼に基づき、ヒント・完全な解答・運営資料を集約した運営者向け版です。参加者向けの `workshop/cpp17-debugging` ブランチへマージしないでください。

**ブランチ分離はアクセス制限ではありません。** 同じリポジトリを閲覧できる参加者は、このブランチと解答も閲覧できます。解答を秘匿する場合、参加者には参加者向けブランチのZIPのみを配布するか、解答を含まない別リポジトリを用意してください。既に閲覧権限がある参加者への秘匿は、このブランチだけでは実現できません。

通常の120分は01～03を使用します。04・05は任意の発展課題として、早く終えたチームや別日の活動に用います。原因を根拠付きで説明できた場合も成果として評価します。

課題の実行用ソースは、このブランチでもバグ入りの状態です。修正済みコードは解答資料内に掲載しています。運営者が解答を確認する場合は別コピーで適用し、参加者へ修正版を配布しないようにしてください。
