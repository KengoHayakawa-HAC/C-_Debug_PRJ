# 運営者用解答：01：HP計算

参加者向けに配布しない資料です。以下は仕様を満たす修正例であり、同じコードだけが正解ではありません。

不具合は、ダメージ後の下限と回復後の上限の処理がないことです。

- 現在HP20、ダメージ35：期待0、配布版−15。
- 現在HP80、最大HP100、回復30：期待100、配布版110。

減算結果を0以上、加算結果を最大HP以下に制限します。条件分岐でも `std::min` / `std::max` でも仕様を満たせます。HP0からの回復は禁止しません。

確認：`ctest --test-dir build-advanced --output-on-failure -R '^hp_spec$'`。11/11判定が成功します。

## 修正例

以下のパスは `debugging-workshop/` からの相対パスです。運営者の別コピーで該当ファイルを置き換えて検証できます。公開テストは変更しません。

### `01-hp/exercise.cpp`

```cpp
#include "exercise.hpp"

int hp::damage(int current, int amount) {
    return current > amount ? current - amount : 0;
}

int hp::heal(int current, int maximum, int amount) {
    return current + amount > maximum ? maximum : current + amount;
}
```
