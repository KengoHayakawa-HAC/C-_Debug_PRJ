# 課題1：HP計算（初級・15～20分）

## Visual Studioの.slnで実行する

教材ルートの [DebuggingWorkshop.sln](../DebuggingWorkshop.sln) を開き、`Debug / x64` でソリューションをビルドします。`hp_demo` をスタートアッププロジェクトに設定し、Ctrl+F5で実行してください。

修正を保存・再ビルドした後、Developer PowerShellで `debugging-workshop` からテストします。

```powershell
ctest --test-dir visual-studio -C Debug --output-on-failure -R '^hp_spec$'
```

Releaseでビルドした場合は `-C Release` にします。詳しくは[共通手順](../README.md)を参照してください。以下にあるプリセット・`build-advanced`・`build-hp`等を使うコマンドは、別方式のCMakeビルド用です。

プレイヤーが攻撃を受けたり、回復アイテムを使ったりする処理です。まず通常時とHPの端での結果を比べましょう。

## 仕様

- 最大HPは1～1000、現在HPは0～最大HP、ダメージ量と回復量は0～1000の整数です。
- ダメージを受けると、その量だけHPが減ります。HPは0より小さくなりません。
- 回復すると、その量だけHPが増えます。最大HPを超えません。
- HPが0でも回復できます。量が0なら変化しません。
- 各入力は独立した1回の操作です。前回の結果は次の入力に引き継ぎません。
- 関数には範囲内の入力が渡されます。入力ミスへの対応はメニュー側の担当です。

| 操作 | 現在HP | 最大HP | 量 | 期待するHP |
|---|---:|---:|---:|---:|
| ダメージ | 80 | 100 | 30 | 50 |
| ダメージ | 20 | 100 | 35 | 0 |
| 回復 | 40 | 100 | 20 | 60 |
| 回復 | 80 | 100 | 30 | 100 |

## 実行方法

共通のビルド手順は[README](../README.md)にあります。Visual Studioで `hp_demo.exe` を選び、Ctrl+F5。起動時のケースで「入力・期待・実際」を比較します。

任意入力例：メニューで `2` → 最大HPに `100` → `80 1 30`（現在HP、操作、量）。期待値を先に記録してから実行します。操作は0がダメージ、1が回復です。


```sh
ctest --preset workshop -R '^hp_spec$'
```

このコマンドは教材フォルダーから実行します。修正を保存し、再ビルドしてから確認してください。

## 完了条件

仕様との差、原因の仮説、確認手段を記録し、修正後に `hp_spec` が成功すること。量0やHP0など、自分たちが選んだ追加の1ケースも説明します。

## 発展課題

回復とダメージを複数回実行する場合の期待値を手計算し、1回ずつ入力して結果を確かめましょう。「戦闘不能中は回復できない」という別仕様なら何が変わるでしょうか。活動中は元の仕様を維持します。
